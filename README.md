# Custom CSS by loveliala

## Overview

This repository contains my custom CSS styles and configurations for various websites and applications.

## Websites

I use [Stylus](https://github.com/openstyles/stylus) to apply custom CSS styles to websites.

- [YouTube](https://www.youtube.com/) — [`sites/youtube-com.css`](./sites/youtube-com.css)
- [2ch](https://2ch.org/) — [`sites/2ch-org.css`](./sites/2ch-org.css)
- [4chan](https://4chan.org/) — [`sites/4chan-org.css`](./sites/4chan-org.css)

## Applications

I use [Vencord](https://vencord.dev/) to apply custom CSS styles to Discord.

- [Discord](https://discord.com/) — [`apps/discord.css`](./apps/discord.css)
